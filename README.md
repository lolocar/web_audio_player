# Simple Audio Player

A web-based audio player whose playlist is driven by a JSON file.

## Files

| File | Purpose |
|---|---|
| `index.html` | Player page |
| `manage.html` | Playlist manager (pick which library tracks play) |
| `style.css` | Styling (player + manager) |
| `manage.css` | Manager page styling |
| `app.js` | Player logic |
| `manage.js` | Manager logic |
| `server.py` | Local server: static files + library/playlist/scan API |
| `server.json` | Server settings (host, port) |
| `library.json` | Full track library (regenerated by `scan.py`) |
| `playlist.json` | The tracks the player plays (the checked subset) |
| `audio/` | Put your audio files here |
| `scan.py` | Scans `audio/` and regenerates `library.json` (CLI); prunes `playlist.json` |

## JSON format

Both `library.json` and `playlist.json` are arrays of objects:

```json
[
  {
    "audio": "audio/track1.mp3",
    "title": "Song Name",
    "album": "Album Name",
    "source": "https://www.youtube.com/watch?v=abc123"
  }
]
```

- `audio` — path to the audio file (mp3, wav, ogg, m4a, flac, whatever your browser supports).
  If the path contains spaces or other special characters, URL-encode it
  (e.g. `audio/My%20Album/01%20-%20Song.mp3`). `scan.py` does this automatically.
- `title` — song name
- `album` — album name
- `source` — optional link to the original (e.g. YouTube URL); shown as a link per track

`library.json` holds every file found under `audio/`; `playlist.json` holds the
subset you selected in the manager. The player reads `playlist.json`.

### Auto-generate the library from the audio folder

```bash
python scan.py
```

Walks `audio/` recursively, finds all audio files, uses the subfolder name as the
album, and strips a leading `NN - ` prefix from filenames to get the title:

```
audio/Merry Christmas [Naxos]/01 - The First Noel.mp3
→  { "audio": "audio/Merry%20Christmas%20%5BNaxos%5D/01%20-%20Song.mp3",
     "title": "The First Noel", "album": "Merry Christmas [Naxos]", "source": "" }
```

Re-run it after adding or renaming files. It rewrites `library.json`, keeps
title/album/source values for files that still exist, and drops any
`playlist.json` entry whose audio file is gone.

## Running

```bash
python server.py                          # use server.json settings
python server.py 9000                     # positional port
python server.py --host 127.0.0.1 -p 9000 # bind only to localhost, port 9000
```

Host and port are read from [server.json](server.json):

```json
{ "host": "0.0.0.0", "port": 8000 }
```

`host` is the bind address — `0.0.0.0` makes the player reachable from other
devices on your network, `127.0.0.1` keeps it local-only. Command-line flags
override the file.

Then open <http://localhost:8000> (player) and <http://localhost:8000/manage.html> (manager).

A plain static server (`python -m http.server`) still works for playback and for
browsing/exporting in the manager, but saving and folder rescanning need `server.py`.

The player picks up changes to `playlist.json` automatically (checked every few
seconds) — no reload needed.

### Playlist manager

Shows every track in `library.json` with a checkbox — checked means it's in
`playlist.json`.

- Toggle checkboxes to build the playlist; **Select all** / **Deselect all**
  apply to the whole library
- `▶` preview a track
- `✕` delete a track — after a confirmation, removes it from `library.json`
  and `playlist.json` **and deletes the audio file from disk**
- **Rescan audio folder** — re-scans `audio/` into `library.json`, keeps saved
  titles/albums/source links for files that still exist, adds new files, and
  drops deleted ones from both `library.json` and `playlist.json`
- **Save playlist** (or `Ctrl+S`, `Cmd+S` on Mac) — writes the checked tracks
  to `playlist.json`; an "Unsaved changes" badge tracks state
- **Export JSON** — downloads the current selection as `playlist.json`
  (works even in read-only mode)

### Server API (server.py)

| Method | Path | Effect |
|---|---|---|
| `GET` | `/api/library` | Return `library.json` |
| `GET` | `/api/playlist` | Return `playlist.json` |
| `POST` | `/api/playlist` | Save body (JSON array) as `playlist.json` |
| `POST` | `/api/scan` | Rescan `audio/` into `library.json`, prune `playlist.json`, return both |
| `POST` | `/api/delete` | Remove `{"audio": …}` from both JSON files and delete the file from disk (paths outside `audio/` are refused) |

## Controls

| Key | Action |
|---|---|
| `Space` | Play / pause |
| `←` / `→` | Seek back/forward 5 s |
| `N` | Next track |
| `P` | Previous track (restarts if > 3 s in) |
| `M` | Mute |
| `S` | Toggle shuffle |
| `R` | Cycle repeat (off → all → one) |

Click a track to play it. Playback continues automatically to the next song.
The **shuffle** button (left of the transport controls) makes next/advance pick
a random track. The **repeat** button cycles three states: **off** (stop at the
end of the playlist), **all** (wrap back to the first track), and **one**
(repeat the current track, shown as a "1" badge on the icon).
